Design decisions — please review before implementation:
  • Font sizes: All text uses only var(--text-xs) (12px), var(--text-sm) (14px), or var(--text-base) (16px). No raw pixel values.
  • Consistent two-line pattern: Both the left-column stamp and the right-column clip list use the same layout — file/timestamp on line 1, note italic and muted on line 2, indented to align under the meaningful content.
  • Single clip with note → two-line layout. Single clip without note → existing chip (no change). This keeps the sightings panel compact when notes aren't used.

  • Stats unaffected: One sighting entry per species per dive — multiple clips don't inflate species counts.
