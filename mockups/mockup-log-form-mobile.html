Mockup v3 — round 2 polish.
  • Dive # annotation: "auto" (was "+1"). Annotation is conditional — shown only while the value is auto-derived. Disappears the moment user manually edits the field. Same rule for Exit time "auto" and Dive type "auto from Dive Vibe".
  • Dive type "auto from Dive Vibe" — runtime-only annotation; shown when a Dive Vibe site match auto-filled the type. Hidden when user manually selects or no match was used.
  • Collapse all ↔ Expand all — same button, toggles label based on state. If any section is open: shows "Collapse all". If all collapsed: shows "Expand all". Tap the button to try it.
  • Free text label: "+ Free text" (was "+ Add free text instead").
  • Trip helper: shortened to "— groups in history".
  • Marine empty state: collapsed summary reads "0 sightings" (not "Tap to add"). Marine always shows a count — the number itself is the summary. Matches the complete state "✓ 3 sightings" in vocabulary.
  • Deco label: italic + --text-dim (one notch dimmer than Safety's --text-muted). Communicates optional without using coral.
  • Save button states: Tap "Save dive" to cycle Default → Saving… → ✓ Saved → Default. Runtime spec: disable button during in-flight; on success briefly show ✓ Saved then reset form.
  • Save bar / keyboard z-index (runtime spec): When species search input has focus and the Android soft keyboard is raised, hide the save bar (set visibility:hidden or translate below viewport using visualViewport.height). Restore on blur. Prevents z-index fight between save bar and autocomplete dropdown.
  • After-save reset spec (runtime, not mockup-visible): On success — (a) Dive # increments by 1; (b) Date stays as logged (don't reset to today — morning-after logging); (c) Trip and region carry forward from last dive; (d) Marine life clears to empty; (e) Dive profile, pressure, notes clear; (f) Dive section reopens, Marine section reopens; (g) scroll to top of form.
